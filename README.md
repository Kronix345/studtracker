# СтудТрекер

Персональний трекер навчальних завдань і дедлайнів для студента. Навчальний проєкт: багатосторінковий статичний сайт-макет (лише HTML і CSS), який показує, як виглядає й працює застосунок з точки зору користувача.

**Команда «Здав-Не-Здав»:** Синюк Антон, Грендач Данило, Леус Станіслав.
**Викладач:** Кундос М.Г.

## Сайтмап

| Сторінка | Файл | Призначення |
|---|---|---|
| Головна | `index.html` | Опис продукту, ключові функції, найближчі дедлайни |
| Завдання | `tasks.html` | Список завдань за дедлайном із кольоровим виділенням |
| Предмети | `subjects.html` | Завдання, згруповані за предметами, із прогресом |
| Календар | `calendar.html` | Дедлайни по днях на два тижні |
| Додати завдання | `add-task.html` | Форма нового завдання |
| Про проєкт | `about.html` | Ідея, функції, команда й ролі |

Стилі лежать в `css/style.css`. Правила коду — у [STYLE.md](STYLE.md).
