# STYLE.md — домовленості про код

Ці правила діють для всієї команди. Якщо хочете їх змінити — спершу домовтеся й оновіть цей файл.

1. **Назви файлів і папок** — малими латинськими літерами через дефіс, без пробілів і кирилиці: `about.html`, `add-task.html`. Сторінки лежать у корені репозиторію.
2. **Де що лежить.** Стилі — у `css/style.css`, зображення — у `img/`. Посилання між сторінками відносні: `tasks.html`, а не повний шлях чи адреса.
3. **CSS-класи** — малими латинськими літерами через дефіс, назва за призначенням, а не за виглядом: `.task-list`, `.badge`, а не `.red-text`. Варіанти оформлення — окремим класом-модифікатором: `.task.urgent`.
4. **Відступи** — 2 пробіли, без табуляції. Кодування файлів — UTF-8, у кожного `<html>` є `lang="uk"`.
5. **Лише HTML і CSS.** Без JavaScript і без атрибута `style="..."` в HTML: усе оформлення — у `css/style.css`.
6. **Однакова структура сторінок.** На кожній сторінці однакові `header.site-header`, `main` і `footer.site-footer`; пункт меню поточної сторінки має клас `active`.
7. **Коментарі** — короткі, українською, перед секцією. У CSS: `/* ---------- Назва секції ---------- */`. У HTML коментуємо лише великі блоки. Кожен `<img>` має `alt`, кожне поле форми — `<label>`.
